## 无法据此定为 parity 缺陷的风险

- **触屏 context menu**：当前 secondary press 路径未提供长按入口；参考 wrapper 尚不足以证明触屏行为。应在设备测试中检查，而非写成已证实的双方差异。
- **小图标命中区域**：部分紧凑控件 token 为 28dp；实际扩展触控目标和平台读屏行为尚未测量，不能直接认定有效命中区域不合格。
- **iOS safe area/IME**：入口忽略 bottom safe area，未发现显式共享 safeDrawing/imePadding；框架可能另行处理，没有已观察的遮挡证据。
- **Android 返回**：NavDisplay 已配置 onBack，不应报告“完全没有返回支持”。overlay 关闭顺序仍待运行验证。
- **字体/颜色/hover/动画**：静态 token、CSS px/rem 与 Compose dp/sp 不能替代同尺寸、同缩放、同主题截图及焦点测试。
